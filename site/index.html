It sees sixteen numbers.

Hidden tiles read as −2 and revealed tiles as their mine count. Two convolutional layers scan every 3×3 neighbourhood, the way you do, and score each tile.

The glow under each tile is how much it wants to click there. Watch it light one tile before the fly lands.

Inside the fly.

Sixteen sensory neurons read the board. Sixteen motor neurons vote on where to land. Between them sit 128 neurons wired from real fruit-fly synapses sampled from the FlyWire connectome: 1,205 feeding in, 203 feeding out.

Positions are drawn for clarity; the wiring density matches the extracted matrix. The moves come from the convolutional network, which plays best.

Did the fly's wiring help?

Not in this setup. A fly-shaped network started from the real connectome scored 59.6%. With the same weights shuffled into random positions it scored 58.5%, a statistical tie. From ordinary random weights it reached 63.3%. Each was trained once, so treat that last gap as unconfirmed.

The bigger lesson is architecture. The convolutional network sees a grid and learns each pattern once for every position. The fly-shaped network sees sixteen unrelated numbers and plateaus near 60%, however it starts.
